Get Flash memory size. 

\begin{DoxyNote}{Note}
For DEV\+\_\+\+ID = 0x416 or 0x427 or 0x429 or 0x437, this field value indicates the Flash memory size of the device in Kbytes.~\newline
 Example\+: 0x0080 = 128 Kbytes.~\newline
 For DEV\+\_\+\+ID = 0x436, the field value can be \textquotesingle{}0\textquotesingle{} or \textquotesingle{}1\textquotesingle{}, with \textquotesingle{}0\textquotesingle{} for 384 Kbytes and \textquotesingle{}1\textquotesingle{} for 256 Kbytes. 

For DEV\+\_\+\+ID = 0x429, only LSB part of F\+\_\+\+SIZE\+: F\+\_\+\+SIZE\mbox{[}7\+:0\mbox{]} is valid. The MSB part F\+\_\+\+SIZE\mbox{[}15\+:8\mbox{]} is reserved and must be ignored. 
\end{DoxyNote}
