155// Sets the return signal rate limit to the given value in units of MCPS (mega counts per second).
156// This is the minimum amplitude of the signal reflected from the target and received by the sensor
157// necessary for it to report a valid reading. Setting a lower limit increases the potential range
158// of the sensor but also increases the likelihood of getting an inaccurate reading because of
159// reflections from objects other than the intended target. This limit is initialized to 0.25 MCPS
160// by default. The return value is a boolean indicating whether the requested limit was valid.

166// Set the measurement timing budget in microseconds, which is the time allowed
167// for one measurement; the ST API and this library take care of splitting the
168// timing budget among the sub-steps in the ranging sequence. A longer timing
169// budget allows for more accurate measurements. Increasing the budget by a
170// factor of N decreases the range measurement standard deviation by a factor of
